CS 370: Pirate Intelligent Agent
Project Overview
For this project, I worked on training an intelligent pirate agent to find treasure in a maze. The goal was to help the pirate learn which moves to make instead of giving it a set path to follow. I used deep Q-learning, which allowed the agent to learn from its experiences and improve its decisions over time.
What Code Was Provided, and What Did I Create?
I was given starter code for the project, including the TreasureMaze environment, the GameExperience class, and parts of the Jupyter Notebook. These provided the maze rules, ways to track the agent's experiences, and functions to help test its performance.

My main job was to complete and improve the training process for the pirate agent. I worked with the deep Q-learning training loop, including how the agent chose actions, balanced exploring new moves with using what it had already learned, and learned from stored experiences. I also adjusted the training process and fixed issues that affected the results. After testing and troubleshooting, my trained agent passed the completion check and successfully found the treasure in the final game test.

How Do I Approach a Problem as a Computer Scientist?
I have learned that it helps to break a big problem into smaller parts and work through them one at a time. During the pirate intelligent agent project, I had to pay attention to the training results, test the model, and go back to the code when something was not working. At one point, the agent was doing well during training but was still not passing the final tests. That showed me why testing is just as important as training.

Instead of assuming the first solution would work, I made changes, checked the results, and kept trying until the agent could complete the maze. I would use that same approach in future projects: understand the problem, build a solution, test it carefully, and improve it based on what I learn.
